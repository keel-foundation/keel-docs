# keel-docs

Public documentation for creators, developers, and instance operators.

## Contents

- `creator/` — uploads, monetization, appeals, exports, safety.
- `developer/` — API, federation, schemas, local development.
- `governance/` — public summaries only. The Constitution and whitepaper are maintained privately until ratification.

## Rules

1. Do not copy the private Constitution or whitepaper into this repo.
2. Do not include secrets, private infrastructure details, or security reports.
3. Keep creator-facing language plain and actionable.
4. Every page should state what it covers and when it was last reviewed.
